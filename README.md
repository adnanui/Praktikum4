Program ini adalah aplikasi console berbasis Java untuk mengelola perpustakaan mini. Pengguna dapat menambah buku, melihat daftar buku, mencari buku, meminjam dan mengembalikan buku, serta melihat laporan aktivitas perpustakaan melalui menu yang dibaca dengan Scanner.
Kode program dibagi menjadi empat package. Package model berisi class Book yang menyimpan judul, penulis, tahun terbit, kategori, dan status ketersediaan buku, serta class Member yang menyimpan id, nama, dan daftar buku yang sedang dipinjam dalam sebuah ArrayList. Package exception berisi tiga custom exception, yaitu BookNotFoundException, BookAlreadyBorrowedException, dan BorrowLimitExceededException. Package service berisi class LibraryService yang menampung seluruh logika program, dan package main berisi class MainApp sebagai menu utama.
Koleksi buku dan anggota disimpan dalam ArrayList, sedangkan statistik peminjaman disimpan dalam HashMap. Buku dapat dicari berdasarkan judul atau kategori dengan toLowerCase() dan contains(), dan jumlah buku pada setiap kategori dihitung dengan looping. Saat meminjam buku, program terlebih dahulu memvalidasi data anggota dengan assertion, lalu memeriksa apakah buku ditemukan, apakah buku masih tersedia, dan apakah anggota belum meminjam lebih dari tiga buku. Setiap kondisi gagal ditangani dengan exception yang sesuai sehingga program tidak berhenti mendadak. Karena assertion tidak aktif secara default, program perlu dijalankan dengan opsi -ea.
Setiap peminjaman yang berhasil dicatat ke dalam statistik, sehingga program dapat menampilkan laporan berisi jumlah total peminjaman, anggota paling aktif, kategori paling populer, dan buku yang paling sering dipinjam. Program ini menerapkan konsep class, object, constructor, package, tipe data primitive dan reference, kondisional, looping, exception, assertion, serta manipulasi Character dan String.
